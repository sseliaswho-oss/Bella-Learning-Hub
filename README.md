Bella's Learning Hub v2 — Unlimited Projects
===========================================

What changed
- Add any number of links with your own names, emojis, categories, descriptions and card colours.
- Edit, remove, reorder and search projects.
- Save changes on your current browser automatically.
- Download an updated index.html with ALL project settings embedded, to share the same hub with everyone and on all devices.
- Export / import a JSON backup of the project list.
- No login, AI or external dependency.

How to update your GitHub Pages home page
1. Keep a backup of your CURRENT published hub index.html, because it may contain your existing links.
2. Open Bella_Learning_Hub_v2.html in a browser or upload it first.
3. Click Parent Setup. Add or update the live GitHub Pages website URLs.
4. Click 'Download updated index.html'.
5. Upload that downloaded index.html to the SAME location as your current hub homepage and commit it.
6. Reload your GitHub Pages homepage. All devices will now see the embedded project links.

Important
- Changes made only on one device using Parent Setup are LOCAL until you download index.html and upload it to GitHub Pages.
- Simply typing new links on your phone will not sync them to other devices.
- The new hub does not change existing maths, writing, theatre or chess website progress.
- Previous three-link hub settings saved locally in the same browser can be migrated when possible.
- If your old hub contains links embedded in its HTML and you replace that HTML before transferring them, re-enter those URLs into the new hub.
- There is no fixed maximum number of projects; browser storage and practical usability are the only constraints.

All interface labels are in English.

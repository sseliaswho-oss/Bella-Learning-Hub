# Bella's Comic Creator Academy — 12 Drawing Missions

A child-friendly, offline English drawing website made for Bella to practise with pencil and paper.

## What's included

- **12 lessons** arranged in 4 stages.
- **Look** at the approved original lesson artwork.
- **Draw** with source-derived drawing steps (Lessons 1–3 and 7–10), or select matching expression faces (Lessons 4–6), or explore story panels (Lessons 11–12).
- **Remix** a character with three optional prompts.
- **Story** to create a short comic or scene.
- Open the **full original poster**, zoom into images, and print an A4 paper practice sheet.
- Completion stars saved in the current browser using localStorage.

## Open locally

Open `index.html` in a modern browser. Keep the `assets/` folder next to it. No network connection or API keys are required.

## Add to Bella Learning Hub

Copy this folder under the site's published public directory, for example:

    public/comic-creator/index.html
    public/comic-creator/assets/...

Then add a navigation link to `/comic-creator/`. If the website is published directly from a GitHub Pages root, copy `comic-creator/` into that published root instead of `public/`.

## Important notes

- Lesson art is drawn from the approved existing posters. This website does **not** invent alternate SVG characters.
- Lessons 4–6 are *expression observation and copy exercises*, not six-stroke construction tutorials.
- Lessons 11–12 are *comic panel/story exercises*, not anatomy drawing tutorials.
- All lessons are designed for paper drawing rather than an on-screen drawing pad.
- Printing opens the browser's print dialog. Select A4 for the worksheet layout.
- Completion progress is local to one browser/device, and is not synced across devices.

Parent Setup ⚙

Add the public web addresses of Bella's three websites.

How to use: Paste each website's live GitHub Pages URL (not its repository editing URL). Select Save & Download, then upload the downloaded index.html to the GitHub repository for this hub. All devices will then see the same links.

You can save links locally for a preview, too. Local previews alone do not sync across devices.
